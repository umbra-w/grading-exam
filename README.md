# Grading_exam · AI 阅卷助手

> 桌面端 AI 阅卷与答题卡智能批改工具原型（开发预览版）。  
> **100% 本地运行、无后端数据上传、支持多模态视觉大模型、MIT 许可。**  
> ⚠ **注意**：本项目目前主要为**桌面端功能框架（原型壳子）**，核心逻辑已通过本地单元测试，但**尚未在真实网阅平台上使用真实账号进行线上实测验证**，自动化填分等功能属于实验性质，使用时请务必人工核对。

---

## 🌟 核心特性

### 1. 📝 本地答题卡批改闭环 (无需外部网阅平台)
- **多图 / PDF 原生导入**：内置 `pdfjs-dist` 无损渲染引擎，支持多页答题卡 PDF 与高清扫描件批量导入，平移缩放流畅自如。
- **交互式题区框选与切片**：可视化框选主观题/客观题区域，生成与分辨率无关的归一化坐标模板；一键切出高清小图送入视觉模型，极大节省 Token 开销。
- **0 Token 纯前端 OMR 客观题填涂识别**：基于 Canvas 像素二值化比率与灰度对比度加权，毫秒级快速识别选项（单选/多选），0 成本秒判客观题。
- **红笔痕迹合成与双模导出**：自动在试卷上盖红笔印章（✓、✗、单题得分徽章、卷头总分双圈印章），一键合成导出批注版高清 PDF 与结构化 Excel 成绩单。

### 2. 🌐 主流网阅模式升级 (人机协同辅助阅卷)
- **主流网阅预设支持**：内置智学网、好分数、七天网络等平台的选择器候选链与安全节流建议。
- **试运行模式 (Trial Run)**：支持“试改 1 份”功能，系统自动识别填分并比对回读，**绝不自动提交**，等待教师人工核验无误后再放行，杜绝误批风险。
- **截图一键提取评分细则**：截取网页或试卷中的评分标准图片，多模态 AI 自动结构化解析为标准题干、满分、参考答案与得分点数组。

### 3. 🖥️ Windows 11 Fluent 现代桌面体验
- **WinUI 3 原生设计语言**：冷灰微透底色、经典 Fluent Blue、亚像素微描边与立体阴影，告别臃肿与廉价感。
- **适度微圆角体系**：卡片统一 8px，按钮与控件 6px，线条利落紧凑，信息密度极佳。
- **浅色 / 暗黑（Light / Dark）无缝双模**：底部状态栏常驻主题切换键，夜间阅卷自适应深空灰石墨暗色。
- **全屏工作台与抽屉式控制台**：运行日志化身滑动抽屉，默认 0 像素完全收起，将 100% 垂直高度完整归还给阅卷区；异常状态一键呼出，支持错误过滤。
- **盲打批改流与悬浮条**：小键盘数字键录分、回车确认、空格翻页；支持一键收缩为边缘迷你悬浮条，不遮挡浏览器。
- **`~` 崩溃恢复协议**：意外断电或强退重启后，横幅自动提醒一键恢复未保存进度与草稿。

## 🛠️ 开发者指南

### 环境依赖
- **Node.js**: `>= 20.19.0`
- **pnpm**: 推荐使用最新版本
- **Python**: `3.10+`（仅用于运行数据评测与自动化检验脚本）
- **操作系统**: Windows 10 / 11

### 安装与运行
```bash
# 1. 安装项目依赖
pnpm install

# 2. 启动本地开发模式
pnpm dev

# 3. 生产打包构建 (产出 portable exe 与 zip)
pnpm dist
```

### 自动化验证与质量守护体系
本项目具备严密的工程质量守护系统，所有模块均通过严苛的单元测试与契约一致性校验：

```bash
# 严格类型检查 (Node 主进程与 Web 渲染进程双端检查)

# 单元测试 (全套 879 项单测覆盖，涵盖 34 套件)

# 全量工程守护套件 (类型 + 测试 + IPC 对账 + 目录树 + 数据集校验 + 评测自测)
```
